# Scheduling

A scheduling tool for idol activities such as concerts, recordings, etc.
Inspired by KAMITSUBAKI STUDIO. (I'm a Big fan of Isekaijoucho!)

> **AI disclosure:** AI is used for consulting (design feedback, explanations).
> All code is written by me.

## Status

Early development. The database schema is drafted ([table.sql](./database/table.sql)); no application code yet.

## Planned features

- Artist schedules (concerts, recordings, streams)
- Song and credit tracking
- Concert setlists
- Birthday and debut anniversary reminders

## Tech

- Backend: ASP.NET Core (C#)
- Frontend: Next.js (TypeScript)
- Database: PostgreSQL
